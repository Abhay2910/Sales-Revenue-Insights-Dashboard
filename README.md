# 📊 Sales & Revenue Insights Dashboard

An interactive **Sales & Revenue Insights Dashboard** built using **Python, Streamlit, Pandas, and Altair**.  
This project visualizes sales performance, identifies top products, and tracks key business metrics — making it a perfect portfolio project for **Data Analyst / Data Science** roles.

---

## 🧠 Project Overview

This project demonstrates a complete data analytics workflow:
- **Data Cleaning & Exploration (EDA)** in Jupyter Notebook  
- **Interactive Dashboard** using Streamlit  
- **Visual Analytics** with Altair charts  
- **Dynamic Filtering, KPIs, and CSV Export**

---

## 🧩 Features

✅ Sales KPIs (Revenue, Units Sold, Average Order Value)  
✅ Time-Series Revenue Trends  
✅ Top Product Performance  
✅ Regional and Channel Analysis  
✅ Interactive Filters (date, region, product, channel)  
✅ Downloadable Filtered Dataset
