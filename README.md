# 📊 Sales & Revenue Insights Dashboard

An interactive **Sales & Revenue Insights Dashboard** built with **Python, Streamlit, and Pandas** to visualize sales trends, track performance metrics, and derive actionable business insights.

This project demonstrates end-to-end **data analysis and visualization skills** — ideal for showcasing in **Data Analyst**, **Data Science**, and **Business Intelligence** portfolios.

## 🧠 Overview

Businesses generate thousands of sales transactions across regions, products, and channels.  
This dashboard helps answer key questions:

- 💰 How are sales and revenue trending over time?  
- 🏆 Which products and regions are performing best?  
- 📦 How do different sales channels compare?  
- 📉 Are there any seasonal patterns or declining categories?  

---

## 🧩 Key Features

✅ **Dynamic KPI cards:** Total revenue, total units sold, average order value  
✅ **Interactive filters:** Filter by date, region, product, and channel  
✅ **Time-series chart:** Visualize revenue trends  
✅ **Top 10 products:** Ranked by total revenue  
✅ **Regional breakdown:** Compare performance across regions  
✅ **CSV export:** Download filtered datasets for deeper analysis
